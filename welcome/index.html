Hướng Dẫn Cụ Thể

Cấu Hình Điện Thoại (Android / iOS)

  • 1Vào Settings > Networking > Bật Enable networking/WLAN.
  • 2Chọn Change PRO ad hoc server IP address và dán: ppsspp.isharoverwhite.com.
  • 3Tắt Enable built-in PRO ad hoc server.
  • 4Đặt Port offset = 0.

Cấu Hình Máy Tính (Windows / macOS)

  • 1Mở PPSSPP, vào Settings > Networking > Bật Enable networking/WLAN.
  • 2Dán Domain Server vào ô Change PRO ad hoc IP.
  • 3Tắt built-in server và đặt Port offset = 0.
  • 4Windows: Cho phép PPSSPP qua Windows Defender Firewall nếu được hỏi.

Cấu Hình Máy PSP Thật (Hardware)

  • 1Tải plugin Pro Online Clientและ chép Atpro.prx vào thẻ nhớ PSP.
  • 2Mở file server.txt, điền ppsspp.isharoverwhite.com.
  • 3Thêm dòng ms0:/seplugins/atpro.prx 1 vào file game.txt.
  • 4Kết nối PSP vào WiFi (chuẩn bảo mật WPA/WPA2) và mở game.
